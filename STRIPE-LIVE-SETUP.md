# Stripe Live Setup — Appex USA Paywall

Пошаговая настройка Stripe для боевого запуска пейволла на США.

> Переключи Dashboard в **Live mode** (тумблер справа вверху).
> В live-режиме всё создаётся с нуля — объекты из test-режима не переносятся.

---

## Что должно получиться

| Объект | Кол-во | Назначение |
|---|---|---|
| Продукт | 1 | Appex Premium |
| Цены | 2 | $38.95 / 4 недели · $127 / год |
| Купоны | 6 | 3 шт. на 61% (intro) + 3 шт. на 71% (exit-intent) |

## Шаг 1. Продукт

**Product catalog → Products → `+ Add product`**

```
Name:        Appex Premium
Description: AI skills course with Claude
```

Нажми **Add product**.

---

## Шаг 2. Две цены

Внутри продукта → блок **Pricing** → **`+ Add another price`**

### Цена A — «4 недели»

```
Pricing model:   Standard pricing
Price:           38.95
Currency:        USD
Billing period:  Custom → Every [4] [weeks]
```

📌 Скопируй ID → **ЦЕНА-A**

> ⚠️ **Обязательно `Custom → 4 weeks`, не `Monthly`.**
> Месяц = 12 списаний в год, 4 недели = 13.
> На пейволле написано «every 4 weeks» — должно совпадать, иначе FTC-риск.

### Цена B — «Год»

```
Price:           127.00
Currency:        USD
Billing period:  Yearly
```

📌 Скопируй ID → **ЦЕНА-B**

---

## Шаг 3. Шесть купонов

**Product catalog → Coupons → `+ New`**

Для **всех шести** одинаково:

- **Type:** `Amount off`
- **Duration:** `Once`
- **Currency:** `USD`

| # | Name | Amount off | Проверка |
|---|---|---|---|
| 1 | Appex intro 1week 61% | **32.02** | $38.95 − 32.02 = **$6.93** |
| 2 | Appex intro 4weeks 61% | **23.76** | $38.95 − 23.76 = **$15.19** |
| 3 | Appex intro annual 61% | **78.00** | $127 − 78.00 = **$49.00** |
| 4 | Appex exit 1week 71% | **33.80** | $38.95 − 33.80 = **$5.15** |
| 5 | Appex exit 4weeks 71% | **27.66** | $38.95 − 27.66 = **$11.29** |
| 6 | Appex exit annual 71% | **90.17** | $127 − 90.17 = **$36.83** |

📌 После создания скопируй **ID** каждого купона (строка вида `AbCd1234` в списке).

> **Почему `Amount off`, а не `Percent off`:**
> Для 1 Week базовая цена $38.95, а нужно получить $6.93 — это 82%, а не 61%.
> «61%» на витрине считается от $17.77 (полная цена недели), а списание идёт
> от 4-недельной цены. Правильные числа даёт только фиксированная сумма.


Отметь события:

- [x] `customer.subscription.updated`
- [x] `customer.subscription.deleted`

📌 Скопируй **Signing secret** (`whsec_…`)

## Шаг 6. Заполнить `.env` на проде

```bash
STRIPE_SECRET_KEY=sk_live_…
STRIPE_WEBHOOK_SECRET=whsec_…

# Цены — 1WEEK и 4WEEK указывают на ОДНУ И ТУ ЖЕ цену:
# оба плана продлеваются за $38.95 каждые 4 недели, отличается только интро-купон
STRIPE_PRICE_1WEEK=<ЦЕНА-A>
STRIPE_PRICE_4WEEK=<ЦЕНА-A>
STRIPE_PRICE_YEARLY=<ЦЕНА-B>

# Купоны 61% (intro — состояние по умолчанию)
STRIPE_INTRO_COUPON_1WEEK=<купон 1>
STRIPE_INTRO_COUPON_4WEEK=<купон 2>
STRIPE_INTRO_COUPON_YEAR=<купон 3>

# Купоны 71% (exit-intent)
STRIPE_EXIT_COUPON_1WEEK=<купон 4>
STRIPE_EXIT_COUPON_4WEEK=<купон 5>
STRIPE_EXIT_COUPON_YEAR=<купон 6>
```

**Удали строку** `STRIPE_INTRO_COUPON_ID=appex_intro_4w_v1` — такого купона не существует.

Перезапусти бэкенд.

(**Payments → выбрать платёж → Refund**).

|---|---|
| 4 Weeks | **$15.19** |

| 1 Week | **$6.93** |

Проверь exit-intent (увести курсор за верхнюю границу окна):

|---|---|

| 1 Week | **$5.15** |

## Как это работает в коде

Скидку выбирает **сервер**, не клиент. Фронт присылает только подсказку
(`intro` / `exit` / `expired`), сервер сам резолвит купон:

```
backend/src/services/stripe.service.ts → couponIdForTier()
```

- Подменить сумму или id купона через запрос **невозможно**
- Невалидный тир → **400** (проверено)
- Если у пользователя уже был платёж → скидка не применяется вообще
- Если exit-купон не задан → откат на **61%**, а не на полную цену
  (лучше недополучить, чем списать полную сумму после обещания скидки)

`discount_tier` пишется в metadata сессии Stripe — можно отличать
61% / 71% / полную цену при сверке выручки.
