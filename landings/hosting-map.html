Where landings live

Marketing landings are static HTML on appex.kz (or another host). The course platform (React SPA) is deployed separately; landings do not load shared scripts from the SPA.

Public URL Source in repo
https://appex.kz/ (main landing) landings/kz/appex-main.html → deploy as site index.html
https://appex.kz/techorda/ (Tech Orda) landings/tech-orda/appexlab-techorda-updated.html — on the server save as techorda/index.html (repo index.html is only a dev redirect).
https://appex-web-frontend.vercel.app/ (SPA, separate deploy) Build appex-web/frontend with VITE_API_URL pointing to your API. Default base /.

Backend CORS_ORIGINS must include https://appex.kz, https://www.appex.kz, https://appex-web-frontend.vercel.app, and local dev origins.
